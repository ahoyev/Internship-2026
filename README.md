## Featured project: SwimTeamManager

**SwimTeamManager** is a Java Spring Boot web application inspired by my experience
as an assistant swim coach. It helps coaches manage a team roster, organize swimmers
by training group, and track daily attendance through a browser dashboard.

The application supports adding, searching, editing, and removing swimmers; marking
swimmers present or absent by date; and saving roster and attendance data to local
files so records remain available after a restart. It builds on my original Java
console application using controllers, services, Thymeleaf templates, and automated tests.

**Technologies:** Java 21, Spring Boot 4.1.2, Maven, Thymeleaf, HTML, CSS, and JUnit.

[View the project and setup instructions](SwimTeamManagerWeb/README.md).

**Live demo:** [Open SwimTeamManager](https://swimteam-web.onrender.com/swimteam-web/).

This free portfolio demo uses fictional, shared records. The first visit after inactivity may take about a minute, and demo data can reset when the host restarts.
